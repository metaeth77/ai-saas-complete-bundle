AI Meeting Summarizer

Turn raw meeting recordings into structured, actionable summaries. Powered by OpenAI Whisper for transcription and Anthropic Claude 3.5 Sonnet for intelligent distillation — no manual notes required.

Audio → Transcript

Upload any meeting recording. Whisper transcribes with speaker diarization and high accuracy.

Transcript → Summary

Claude extracts key decisions, action items, and talking points in structured JSON output.

API-Ready Output

Return summaries to any frontend or downstream automation via clean FastAPI REST endpoints.
